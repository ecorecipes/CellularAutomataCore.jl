Overview and exceptions

CellularAutomataCore — Module
CellularAutomataCore

Cellular automata with one model specification and pluggable backends: the Catlab-free core of the ecorecipes cellular-automata ecosystem.

The package separates what a cellular automaton is from how it runs:

  • a space (Torus, Grid, HexGrid, GraphSpace) with boundary conditions (Periodic, Reflecting, Constant);
  • a rule: a neighbourhood (Moore, VonNeumann, Hexagonal, Offsets) and a local rule, either a built-in family (Wolfram, Totalistic, Life, Generations, Lenia) or any function (LocalRule). A local rule in the sense of (Ceccherini-Silberstein and Coornaert, 2010), a finite neighbourhood S and a map μ : A^S → B, is written once and runs everywhere;
  • a state: an array the size of the space, or a NamedTuple of arrays for several layers;
  • an environment: covariate layers, dispersal-kernel fields (KernelField) and masks;
  • an update scheme, the algorithm (Synchronous, Stochastic, Checkerboard, RandomSequential, Margolus, Gillespie), and a backend (ArrayBackend, SparseBackend, GPUBackend, AgentsBackend, ArkBackend, ReferenceBackend), chosen when the problem is solved.

Stochastic rules draw counter-based random numbers (uniform), so a model gives the same result on every backend and thread count. Problems follow the SciML interface: solve(CAProblem(rule, u0, tspan, p), alg; saveat, callback), with SciMLBase callbacks, remake and ensembles; abc_rejection calibrates a model against observations on an ensemble.

This package depends on no category-theory library. CategoricalCellularAutomata.jl builds the categorical layer on top of it.

Part of the ecorecipes cellular-automata ecosystem.

Exceptions

Every exception the package defines subtypes the abstract root CellularAutomataCoreError. Invalid arguments and keywords raise Base's ArgumentError, which is outside it.

CellularAutomataCore.CellularAutomataCoreError — Type
CellularAutomataCoreError

Abstract supertype of every exception that CellularAutomataCore defines: RuleParseError, RLEParseError, StateShapeError, InvalidStateError, IncompatibleSpaceError and UnsupportedCombinationError. It marks the package that introduced an error, not a kind of failure. Invalid arguments and keywords raise Base's ArgumentError instead, which is outside this root.

julia> try
           Life("B9/S23")
       catch e
           e isa CellularAutomataCoreError
       end
true

CellularAutomataCore.RuleParseError — Type
RuleParseError(rule, msg)

Thrown when a rule string such as "B3/S23" or "B2/S/C3" cannot be parsed. rule is the offending string.

source
CellularAutomataCore.RLEParseError — Type
RLEParseError(line, msg)

Thrown when run-length-encoded (RLE) pattern text cannot be parsed. line is the 1-based line number of the offending text, or 0 when the problem is not tied to one line.

source
CellularAutomataCore.StateShapeError — Type
StateShapeError(what, expected, got)

Thrown when a state does not have the size of its space. what names the offending state or layer; expected and got are the sizes.

source
CellularAutomataCore.InvalidStateError — Type
InvalidStateError(rule, index, value, msg)

Thrown when an initial state holds a value that the rule cannot read, for example a 2 in a two-state rule. rule names the rule, index is the first offending cell and value its value. States are checked once, when a problem is constructed, never during a run.

source
CellularAutomataCore.IncompatibleSpaceError — Type
IncompatibleSpaceError(what, space, msg)

Thrown when a neighbourhood, rule or state cannot be used on a space, for example a Moore neighbourhood on a hexagonal grid or a one-dimensional rule on a two-dimensional lattice. what names the offending object and space describes the space.

source
CellularAutomataCore.UnsupportedCombinationError — Type
UnsupportedCombinationError(backend, scheme)

Thrown when a backend does not support an update scheme. backend and scheme name them; supports answers the same question without throwing.
